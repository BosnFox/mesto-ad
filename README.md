## Mesto

Учебный проект по курсу Яндрекс.Практикум "Ассоциированные программы: frontend-разработчик".

### Обзор проекта

Приложение позволяет размещать фотографий, редактировать профиль и аватар, добавлять и удалять карточки, ставить лайки и просматривать изображение в модальном окне.

### Технологии
- HTML5, CSS3
- Ванильный JavaScript
- Vite
- GitHub Pages

## Установка и запуск проекта

### Запуск локального сервера разработки
\`\`\`bash
npm run dev
\`\`\`

### Сборка проекта
\`\`\`bash
npm run build
\`\`\`

### Публикация проекта
\`\`\`bash
npm run deploy
\`\`\`
